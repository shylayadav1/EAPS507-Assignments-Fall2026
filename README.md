# Assignments for EAPS 507 – Fall 2026

This repository contains completed Jupyter notebook (`.ipynb`) assignments for EAPS 507 (Introduction to Analysis of Geological Data) from Fall 2026, focusing on scientific computing, numerical methods, array operations, and earth/geological data analysis in Python.

## Assignments

1. **Madhava Pi Calculation**: Numerical approximation of pi using the Madhava-Leibniz series expansion and analysis of series convergence.
2. **Trigonometric Functions (`trig function`)**: Implementation and evaluation of trigonometric functions using series expansions and numerical approximations in Python.
3. **Calculating e (`calculating_e`)**: Numerical computation of Euler's number (e) using infinite series and limit formulations.
4. **Multidimensional Arrays (`multidimensional array`)**: Creation, indexing, slicing, broadcasting, and vectorized computation with multidimensional NumPy arrays.
5. **Data Manipulation (`data manipulation`)**: Loading, cleaning, filtering, transforming, and analyzing structured scientific datasets in Python.
6. **Xarray (`xarray`)**: Handling, subsetting, and analyzing labeled multidimensional scientific and geospatial datasets using the Xarray library.
